# E*TRADE API and Scripts

## When to use this skill

- Adding a new E*TRADE API call or route
- Writing a new script that fetches quotes, places orders, or lists accounts
- Implementing or debugging OAuth for E*TRADE

## Documentation (reference first)

- **Full API reference**: [etrade-documentation/ETRADE API COMPLETE DOCUMENTATION COM.md](../../etrade-documentation/ETRADE API COMPLETE DOCUMENTATION COM.md) — canonical E*TRADE API endpoints, request/response shapes, and rules. Use when implementing or extending API calls.
- **API test summary**: [etrade-documentation/api-test-results/API_TEST_SUMMARY.md](../../etrade-documentation/api-test-results/API_TEST_SUMMARY.md) — summary of tested endpoints and behaviors (generated by test scripts; may exist only after runs). Consult when adding or changing API usage.

## OAuth (src/scripts/oauth-flow.ts)

- **Flow**: Request token (GET `/oauth/request_token` with `oauth_callback=oob`) → user authorizes at E*TRADE URL → access token (GET `/oauth/access_token` with `oauth_verifier`).
- **OAuth base URL** is always `https://api.etrade.com` (production) for token endpoints; **API base** is sandbox (`https://apisb.etrade.com`) or production by `ETRADE_SANDBOX`.
- **Env keys**: Sandbox = `ETRADE_SANDBOX_KEY`, `ETRADE_SANDBOX_SECRET`, `ETRADE_SANDBOX_ACCESS_TOKEN`, `ETRADE_SANDBOX_ACCESS_TOKEN_SECRET`. Production = `ETRADE_CONSUMER_KEY`, `ETRADE_CONSUMER_SECRET`, `ETRADE_ACCESS_TOKEN`, `ETRADE_ACCESS_TOKEN_SECRET`.
- **Saving tokens**: Script can write tokens to `.env` via `updateEnvFile()`; keys are `ETRADE_*_ACCESS_TOKEN` and `ETRADE_*_ACCESS_TOKEN_SECRET` (sandbox vs production). Non-interactive: `ETRADE_OAUTH_PHASE=2 ETRADE_VERIFIER=<code> ETRADE_SAVE_TOKENS=y`.

## Script setup (credentials and client)

1. **dotenv**: `dotenv.config({ quiet: true })` to avoid dotenv v17 console message.
2. **Sandbox vs production**: `const isSandbox = process.env.ETRADE_SANDBOX === 'true';`
3. **Credentials object** (same shape in all scripts):

```ts
const credentials: ETradeCredentials = isSandbox
  ? {
      consumerKey: process.env.ETRADE_SANDBOX_KEY!,
      consumerSecret: process.env.ETRADE_SANDBOX_SECRET!,
      accessToken: process.env.ETRADE_SANDBOX_ACCESS_TOKEN,
      accessTokenSecret: process.env.ETRADE_SANDBOX_ACCESS_TOKEN_SECRET,
    }
  : {
      consumerKey: process.env.ETRADE_CONSUMER_KEY!,
      consumerSecret: process.env.ETRADE_CONSUMER_SECRET!,
      accessToken: process.env.ETRADE_ACCESS_TOKEN,
      accessTokenSecret: process.env.ETRADE_ACCESS_TOKEN_SECRET,
    };
```

4. **Validate** consumer key/secret and access token/secret; exit with clear message if missing (e.g. "Please run the OAuth flow first" for tokens).
5. **Client**: `const client = new ETradeClient(credentials, isSandbox);` from `../server/services/etrade-client.js`.

## Quotes

- **Call**: `const quotes = await client.getQuote(['SYMBOL']);` (or multiple symbols).
- **Response shape**: API returns market data **inside `quote.All`**, not on the top-level quote. `getQuote()` is typed as `ETradeQuote[]` but the real shape has `All`. Use:

```ts
// Type for raw market data (optional fields)
interface ETradeQuoteAll {
  lastTrade?: number;
  previousClose?: number;
  bid?: number;
  ask?: number;
  bidSize?: number;
  askSize?: number;
  totalVolume?: number;
  previousDayVolume?: number;
  high?: number;
  low?: number;
  open?: number;
  changeClose?: number;
  changeClosePercentage?: number;
  companyName?: string;
  symbolDescription?: string;
  exDividendDate?: number;
  dividend?: number;
  lastSize?: number;
  timeOfLastTrade?: number;
}

const quote = quotes[0] as ETradeQuoteAll & { All?: ETradeQuoteAll };
const quoteData: ETradeQuoteAll = quote.All ?? quote;
```

- **Field names**: Use `lastTrade` (not `last`), `totalVolume` (not `volume`), `changeClose` / `changeClosePercentage`, `previousClose` (not `close`).

## Accounts

- **List**: `const accounts = await client.getAccounts();`
- **Account selection**: Filter `accountStatus === 'ACTIVE'`. Optional `ACCOUNT` env = suffix of `accountId` (e.g. last 4 digits). Pick matching account or fallback to first active. Use `accountIdKey` for API calls (e.g. orders).

## Orders

- **Request shape** (`ETradeOrderRequest` in `src/shared/types/etrade.ts`): `accountIdKey`, `symbol`, `securityType: 'EQ' | 'OPTN'`, `orderAction`, `clientOrderId` (≤20 alphanumeric), `priceType`, `quantity`, `orderTerm`, `marketSession`, and optionally `limitPrice`, `stopPrice`. For options add `callPut`, `expiryYear/Month/Day`, `strikePrice`, and optionally `productId: { symbol: osiKey, typeCode: 'OPTION' }`.
- **Place**: Prefer `await client.placeOrder(request)` (preview then place). For no preview: `await client.placeOrderDirect(request)` when `SKIP_PREVIEW=true`.
- **Success**: Response has `OrderIds` array; e.g. `(response as any).OrderIds?.[0]?.orderId`.

## Server (API routes)

- **ETradeClient** is obtained via `getETradeClient()` (or equivalent) in routes; credentials come from env. Quote route: `GET /api/orders/market/quote?symbols=AAPL,MSFT` → `client.getQuote(symbolArray)`.
